# Software-Engineering-Group-Project

#System Overview

Our system is a college-based lost-and-found system in which staff and students can register to create an account. These accounts allow staff and students to register lost items, to claim items, and to search through items.

#Setup Instructions (Configuration Manual)

1) Click the register button on the main login page to create a new account
2) Follow the necessary steps to create a new account
3) Click the login button on the main login page to log in to a preexisting account
4) Type in your username and password to log in
5) Go to the Lost tab in the navigation  bar to report a lost item/items
6) Fill in the form on the Lost page to report a lost item/items
7) Go to the Found tab in the navigation bar to report an item/items you have found
8) Fill in the form on the Found page to report an item/items that you have found
9) Go to the search bar and type in a random search term to look at items that match your chosen search term
